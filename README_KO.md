# MARK Mobile — 아이폰 제어형 개인 AI 비서

원본: https://github.com/fatihmakes/mark-lii
원본 복제 커밋: 476a9c0
전환 버전: 0.2.0 · iOS 17 이상 · SwiftUI

이 폴더는 PC 없이 사용하는 네이티브 아이폰 앱 개발 프로젝트입니다. PC 제어, PC 서버, LAN 대시보드 연결은 포함하지 않습니다. 원본의 Python/PyQt 앱을 iOS에서 직접 실행하는 방식이 아니라, 대화 기능을 SwiftUI로 다시 구현하고 아이폰용 실행 기능을 연결했습니다.

TestFlight 준비 절차는 **TESTFLIGHT_KO.md**를 먼저 확인하세요.

## 현재 전달 상태

- 포함: Xcode 프로젝트, Swift 소스, 앱 아이콘, 권한 설명, 개인정보 매니페스트, 원본 라이선스.
- 구현: Gemini 텍스트/사진 질문, 한국어 음성 입력과 음성 읽기, 기기 내 대화 기록, Keychain API 키 보관, 아이폰 실행 확인 화면.
- 이 Linux 환경에서는 Xcode 빌드, iOS 시뮬레이터, 실제 아이폰 설치를 실행할 수 없습니다. 소스/프로젝트 정적 검증 결과는 VALIDATION.md를 참조하세요.
- API 키가 제공되지 않아 Gemini 실서버 대화도 검증하지 않았습니다.
- 서명된 IPA나 App Store/TestFlight 배포본이 아닙니다. ZIP을 아이폰에서 눌러 바로 설치할 수 없습니다.

## Mac에서 아이폰에 설치하기

1. ZIP을 Mac에서 압축 해제합니다.
2. `MarkMobile.xcodeproj`를 Xcode에서 엽니다. 추가 패키지 설치는 없습니다.
3. 프로젝트 → `MarkMobile` 타깃 → Signing & Capabilities에서 본인의 Apple 개발 Team을 선택합니다.
4. Bundle Identifier `com.personal.markmobile`을 본인에게 고유한 값으로 변경합니다.
5. 아이폰을 Mac에 연결하고 신뢰/개발자 모드 안내를 따릅니다.
6. Xcode 실행 기기로 아이폰을 선택하고 ▶ Run을 누릅니다.
7. 앱이 열리면 상단 아이폰 버튼으로 기기 기능부터 사용할 수 있습니다. 기기 명령에는 Gemini 키가 필요하지 않습니다.
8. AI 대화가 필요하면 설정 → 개인 Gemini API 키 입력 → ‘키 저장 · 모델 불러오기’ → 사용할 모델 선택 순서로 연결합니다.

시뮬레이터 빌드 확인 명령:

```sh
xcodebuild -project MarkMobile.xcodeproj -scheme MarkMobile \
  -sdk iphonesimulator -configuration Debug \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO build
```

Gemini 모델은 계정에서 조회한 목록을 사용합니다. 사진 질문을 하려면 이미지 입력을 지원하는 모델을 선택하세요. API 사용료와 쿼터는 본인 Google 계정에 따릅니다. 키를 소스에 넣거나 채팅으로 전달할 필요가 없습니다.

## Jauvex 연결 (코딩 에이전트)

MARK는 컴퓨터에서 실행 중인 [Jauvex](https://github.com/happytalkman/code-jauvex)의 에이전트(Claude, Codex, ZCode, Claw)와도 대화할 수 있습니다. Gemini 대화는 그대로 두고, 왼쪽 위 메뉴에서 대화 상대를 바꿉니다.

1. 컴퓨터에서 Jauvex 웹 버전을 `CVC_WEB_LAN=1 npm run web`으로 시작합니다. 폰용 링크(`http://<컴퓨터 주소>:4343/mobile?token=…`)가 출력됩니다.
2. MARK 설정 → Jauvex 연결에 그 링크를 붙여 넣고 ‘링크 저장 · 연결 확인’을 누릅니다. 토큰은 Keychain에 저장됩니다.
3. 왼쪽 위 메뉴(…) → Jauvex 에이전트에서 폴더의 에이전트를 고르거나 ‘새 에이전트’로 엽니다. ‘MARK (Gemini)’를 고르면 원래 대화로 돌아옵니다.

에이전트와 대화할 때는 Jauvex가 판단합니다: “스크래치 폴더에 새 코덱스 에이전트 만들어줘” 같은 명령, “잠깐만”·“잘 자” 같은 대기·작별, 작업 중에 한 말의 반영/대기열/중지/교체, Jev의 빠른 한국어 응답, 도구 사용 권한 확인. 답변은 한국어/영어 문장에 맞는 음성으로 읽습니다. 앱 재시작은 폰에서 하지 않습니다(서버가 멈추면 폰에서 다시 켤 수 없음). 같은 Wi-Fi에서만 연결되고 토큰이 일반 HTTP로 오가므로 믿을 수 있는 네트워크에서만 사용하세요. 같은 화면을 브라우저로 보려면 링크를 폰의 Safari로 열면 됩니다.

## 아이폰 제어 기능

| 기능 | 실제 실행 방식 | 확인 사항 |
|---|---|---|
| 미리 알림 | EventKit으로 기본 목록에 저장 | 최초 권한 허용, 제목/기한 확인 |
| 일정 | Apple 일정 작성 화면 | 날짜 수정 후 Apple 화면에서 저장 |
| 예약 알림 | MARK 로컬 알림 예약 | 시계 앱 알람과 다르며 집중 모드 영향 |
| 전화 | 입력 번호를 `tel:`로 전달 | 번호 확인, 시스템 통화 화면 |
| 문자 | Apple 문자 작성 화면 | 번호와 내용 확인 후 사용자가 전송 |
| 지도 | Apple 지도 검색 | 위치 권한 없이 입력한 장소 검색 |
| 단축어 | 설치된 Apple 단축어 이름으로 실행 | 단축어를 먼저 만들고 권한 확인 |

채팅에서 다음과 같이 입력하거나 마이크로 말한 후 전송하세요. 앱이 내용을 실행 확인 화면으로 넘깁니다. 이 형식의 기기 명령은 Gemini로 보내지 않습니다.

- `미리알림 우유 사기`
- `일정 다음 회의` — 실제 날짜/시간은 확인 화면에서 지정
- `알림 10분 후 물 마시기`
- `지도 강남역`
- `전화 01012345678` — 예시 번호 대신 실제 번호 입력
- `문자 조금 늦겠습니다` — 수신 번호는 확인 화면에서 지정
- `단축어 손전등 켜기`

‘미리 알림’처럼 띄어쓴 접두어도 지원합니다. 지원 형식 밖의 문장은 일반 AI 질문으로 처리합니다. 자연어 임의 표현 전체를 이해하는 자율 기기 제어 에이전트는 아닙니다. AI 답변 자체가 실행 도구를 호출하지 않습니다.

## 손전등·밝기·음량·앱 실행 연결

Apple 단축어 앱에서 아래 이름으로 각각 생성합니다. MARK에 정확히 같은 이름을 입력해야 합니다.

| 단축어 이름 예시 | 단축어에 추가할 동작 |
|---|---|
| 손전등 켜기 | 손전등 설정 → 켬 |
| 손전등 끄기 | 손전등 설정 → 끔 |
| 밝기 50 | 밝기 설정 → 50% |
| 음량 30 | 음량 설정 → 30% |
| 카메라 열기 | 앱 열기 → 카메라 |

단축어는 이 ZIP에 설치 파일로 포함되어 있지 않습니다. 기기에서 직접 생성해야 합니다. MARK는 단축어 실행 요청 전달 여부만 알 수 있으므로, 실제 성공 여부는 열린 단축어 앱에서 확인합니다.

## 개인정보와 권한

- API 키는 해당 기기의 Keychain에 저장하며 백업으로 이동하지 않는 접근 등급을 사용합니다.
- 대화 텍스트는 앱 컨테이너에 파일 보호를 적용해 저장하고 백업 제외를 요청합니다. 상단 메뉴에서 삭제할 수 있습니다.
- 사진은 전송 시 최대 1600픽셀로 변환해 사용하고, 성공 후 기록에 사진 데이터를 남기지 않습니다.
- Google Gemini에는 현재 질문/사진과 최근 최대 20개 메시지가 전송됩니다.
- 음성 입력은 Apple Speech를 사용하며 Apple 서버에서 처리될 수 있습니다. 녹음 파일은 별도로 저장하지 않습니다.
- 기기 명령은 앱 내에서 처리합니다. 전화·문자 수신자는 앱에서 직접 입력하고 확인합니다.
- 기본적으로 지속적인 백그라운드 녹음, 위치 추적, 연락처 읽기, PC 연결은 없습니다.
- 미리 알림은 iOS가 제공하는 전체 접근 권한을 요청하지만, 코드에서는 기본 목록에 새 항목을 추가하는 데만 사용합니다.
- 배포 전 실제 서비스 운영 방식에 맞는 개인정보처리방침, App Store 개인정보 응답, Google/Apple 데이터 처리 조건 검토가 필요합니다. 매니페스트만으로 배포 준비가 완료된 것은 아닙니다.

## 원본과의 차이 및 제한

- 원본의 Gemini Live 실시간 양방향 음성 대신 ‘음성 인식 → 텍스트 확인/전송 → 텍스트 답변 → 읽어주기’를 구현했습니다.
- 원본 PC 플러그인·화면 캡처·마우스 조작·파일 시스템 제어·홀로그램 얼굴은 이 버전에 이식하지 않았습니다.
- iOS의 다른 앱 화면을 마음대로 누르거나 잠금 해제, 접근 제어 우회, 임의의 시스템 설정 변경을 하지 않습니다.
- 앱이 백그라운드로 가면 녹음과 읽어주기는 중지됩니다. 백그라운드 AI 요청 완료는 보장하지 않습니다.
- 예약 알림의 취소/관리는 iOS 설정 및 향후 앱 관리 화면 확장 대상입니다. 테스트 시 짧은 시간으로 예약하세요.
- 음성 인식, 전화, 문자, 실제 권한 동작은 아이폰에서 검증해야 합니다.
