# TestFlight 입력 초안

## 베타 앱 설명
MARK Mobile은 한국어 대화와 아이폰 작업을 연결하는 개인 AI 비서입니다. 마이크로 질문을 입력하고, 사진을 첨부하여 질문하고, 답변을 음성으로 들을 수 있습니다. 미리 알림·일정·예약 알림·전화·문자·지도·Apple 단축어는 실행 내용을 확인한 뒤 사용합니다. 기기 기능은 API 키 없이 테스트할 수 있습니다. AI 대화에는 본인의 Google Gemini API 키가 필요합니다.

## 테스트할 내용
1. 상단 아이폰 버튼 → 미리 알림 추가 → 기본 목록에 저장되는지 확인.
2. `알림 1분 후 테스트` 입력 → 시간 확인 → 예약 후 앱을 열어둔 상태와 백그라운드 상태에서 각각 확인.
3. 일정 작성 → 저장/취소 결과 확인.
4. 본인의 테스트용 전화번호로 문자 작성 → Apple 작성 화면에서 내용 확인 후 취소.
5. `지도 강남역` 입력 → 지도 검색 확인.
6. 직접 만든 `손전등 켜기` 단축어 실행.
7. 개인 Gemini 키 저장 → 모델 선택 → 텍스트/사진 질문.
8. 마이크 권한 거절·허용, 녹음 종료, 네트워크 실패·재시도, 대화 삭제 확인.

## 심사 메모 초안
별도 MARK 계정 로그인은 없습니다. 기기 기능은 앱 오른쪽 상단 아이폰 버튼으로 접근할 수 있습니다. 화면에 표시되는 실행 내용을 확인해야 저장/외부 앱 실행이 진행됩니다. 문자 전송은 Apple 작성 화면에서 사용자가 최종 전송합니다.

AI 기능은 개인 Gemini API 키를 입력하는 방식입니다. 검토자가 AI 기능까지 접근할 수 있는 테스트 방법/인증 정보 제공 방안은 제출자가 실제로 준비해야 합니다. 현재 패키지에 검토용 키는 포함되어 있지 않습니다.

음성 입력은 Apple Speech, 답변 생성은 Google Gemini, 음성 읽기는 AVSpeechSynthesizer를 사용합니다. PC 제어, 상시 백그라운드 녹음, 다른 앱 화면 자동 조작은 제공하지 않습니다.

## 제출자가 채울 항목
- 베타 피드백 이메일
- 실제 심사 연락 담당자 이름/이메일/전화
- 운영 주체와 데이터 처리 내용을 반영한 개인정보처리방침 URL
- 필요한 AI 기능 검토용 접근 방법
- 계정에 표시되는 암호화/수출 관련 질문의 실제 답변

## 알려진 제한
- 지원 접두어에 따른 기기 명령 처리이며 임의 자연어 기기 조작은 지원하지 않습니다.
- 단축어는 사용자가 아이폰에 먼저 만들어야 합니다.
- 예약 알림은 시계 앱 알람이 아니며 집중 모드의 영향을 받습니다.
- Gemini Live 실시간 음성 대신 음성 인식/텍스트 요청/답변 읽기를 사용합니다.
- 실제 빌드 및 기기 테스트가 아직 실행되지 않은 소스 전달본입니다. 테스트 결과를 확인한 뒤 제출해야 합니다.
